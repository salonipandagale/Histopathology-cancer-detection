# Histopathology Cancer Detection & Explainability

A deep learning-based computer vision project for detecting cancerous tissue in histopathology image patches using **ResNet18, transfer learning, image augmentation, and Grad-CAM explainability**.

The project explores the application of **AI in Digital Pathology**, combining image classification with interpretable predictions through visual attention maps.

---

## Live Demo
https://histopathology-cancer-detection.onrender.com

Upload a histopathology image patch to get:

- Cancer / Normal prediction
- Cancer probability
- Model confidence
- Grad-CAM visualization of important image regions
